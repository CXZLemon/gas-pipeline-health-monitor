# 简历写法与面试指南

## 简历项目描述

**天然气管道运行异常检测与可视化平台｜个人项目**

- 基于 Pandas 构建管道压力、流量和温度时序数据清洗与特征工程流程，提取压降、变化率、滚动统计量及时间周期特征。
- 使用 StandardScaler 与 Isolation Forest 建立无监督异常检测基线，将检测结果转换为 0–100 风险分数，并利用合成注入异常计算 Precision、Recall 和 F1。
- 使用 Streamlit 与 Plotly 实现管段筛选、趋势分析、高风险记录展示和 CSV 导出，通过 SQLAlchemy 支持 SQLite 本地存储及 MySQL 连接。
- 编写 pytest 单元测试并配置 GitHub Actions，实现数据校验、特征构造、模型输出和数据库读写的自动检查。

注意：简历中只写自己真正运行、理解和能够解释的功能；在没有真实数据验证前，不要写“准确识别真实泄漏”。

## 1 分钟项目介绍

这个项目面向天然气管道运行数据的异常筛查。考虑到工业现场异常标签少，我先用可复现的合成数据模拟压力、流量和温度的周期变化，并注入泄漏、堵塞和传感器漂移三类异常。数据处理阶段，我用 Pandas 构造压降、流量变化率、滚动均值和滚动标准差等特征；模型阶段使用标准化加 Isolation Forest，在不使用异常标签训练的情况下输出异常点和风险分数。工程上，我用 Streamlit 和 Plotly 做交互页面，用 SQLAlchemy 支持 SQLite 和 MySQL，并用 pytest 和 GitHub Actions保障核心流程。这个项目让我补充了从时序数据处理、机器学习基线到可视化交付和自动化测试的完整实践。

## STAR 表达

- **S 情境**：管道遥测数据量大，但异常标签稀缺，人工逐条检查成本高。
- **T 任务**：建立一个容易运行和解释的异常筛查原型，并形成可展示的应用。
- **A 行动**：生成合成数据和异常标签；构造领域与时序特征；训练 Isolation Forest；设计风险分数；开发页面、数据库层和自动化测试。
- **R 结果**：形成从数据输入到结果导出的完整闭环，可用注入标签离线比较 Precision、Recall 和 F1，并能快速替换真实 CSV 数据继续验证。

## 高频问题与参考答案

### 1. 为什么不用有监督分类

真实工业数据中正常样本多，异常样本少，而且异常原因的人工标注成本高。Isolation Forest 不需要标签，适合先建立筛查基线。若后续积累了高质量标签，我会按时间切分数据，对比 XGBoost 等监督模型，并重点关注 Recall、误报率和告警成本。

### 2. 为什么需要标准化

压力、流量、温度和变化率的量纲不同。虽然树模型通常不强制标准化，但统一尺度便于后续替换距离模型或神经网络，也使特征处理流程更一致。这里用 Pipeline 把标准化和模型绑定，避免训练与推理使用不同处理方式。

### 3. contamination 如何选择

它代表预计异常比例并影响判定阈值。学习项目用合成异常比例作为初值；真实项目应结合历史告警数量、人工处理能力和误报漏报成本，在按时间划分的验证集上做灵敏度分析，不能凭感觉固定。

### 4. 风险分数是不是异常概率

不是。本项目把 Isolation Forest 的决策分数做区间缩放，得到便于排序和展示的 0–100 分数。它表示相对异常程度，不是经过概率校准的故障概率，因此页面和文档都不能把它称为泄漏概率。

### 5. 如何避免数据泄漏

当前无监督演示在同一批数据上拟合和评分，适合展示但不是严格上线评估。实际项目应使用较早的稳定运行区间拟合模型，使用后续时间段测试；滚动特征只使用当前及过去数据；标准化参数只从训练期计算；异常标签只用于评估，不进入特征。

### 6. 如何减少误报

先提高数据质量，处理传感器坏点、维护停机和工况切换；再按管段或工况分别建模；之后将统计异常与压力变化阈值、流量不平衡等物理规则联合；最后加入告警持续时间、冷却时间和人工确认闭环。

### 7. SQLite 和 MySQL 如何选择

SQLite 是嵌入式单文件数据库，部署简单，适合个人演示和单机工具；MySQL 是客户端—服务器架构，更适合多人访问、权限控制和并发写入。项目通过 SQLAlchemy 抽象连接方式，但迁移到 MySQL 后还需要增加字段类型、索引、连接池和并发测试。

### 8. 如果数据规模扩大怎么办

数据层可按时间和管段分区读取，避免一次加载全部历史；数据库为 `component_id` 和 `timestamp` 建联合索引；特征计算使用分批或流式窗口；模型可以按管段分别训练，并将离线训练与在线评分解耦。

## 应掌握的技术清单

- Pandas：`groupby`、`diff`、`rolling`、时间字段、缺失值处理。
- scikit-learn：Pipeline、StandardScaler、Isolation Forest、模型评估指标。
- 数据库：参数化查询、SQLite 与 MySQL 差异、索引、事务和连接池。
- Streamlit：脚本重运行机制、缓存、组件交互和文件下载。
- 测试：测试边界条件、确定性随机种子、临时数据库和 CI。
- 工业常识：统计异常不等于故障结论，安全相关决策必须人工复核。
